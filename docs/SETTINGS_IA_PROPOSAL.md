## 三、提案（单一设置结构，macOS 侧栏 + 分栏惯例）

**结构**：一个设置容器（sheet 或窗口，二选一，见 §五 D-7）＝ **左侧 6 栏 sidebar + 右侧 pane**；
pane 内用 `Section` 分小组；**取消"摘要页 vs 编辑页"双轨**。

| 新 pane | 吸收自 | 说明 |
|---|---|---|
| 概览 | 轨 B 全部 5 卡的**只读部分** | 定位为"状态概览"（工作区根目录/模型摘要/插件数/向量库路径/当前主题），每行带**「编辑…」跳转**到对应 pane → 修 IA-1/IA-3（要么可操作要么改名） |
| 通用 | A 偏好 | 语言/外观偏好 |
| 通知与沙箱 | A 通知 + 文件沙箱 | 权限/边界同类合并 |
| 模型 | A 提供商与密钥 + 请求参数 + 连接测试 | 一条任务流：配密钥 → 调参数 → 测连通 |
| 插件与主题 | A 插件管理 + 轨 B 主题 Picker | 主题=插件类（我们的主题全插件化口径）；含 glassTint/材质明示 |
| 数据与记忆 | 轨 B 工作区 + RAG 记忆参数（**升为可编辑**） | 修 IA-4，同类能力一致 |
| 关于 | A 关于 Harness | 版本/日志/反馈 |

（7 行含概览；若嫌多可并「关于」入「概览」页脚 → 6 pane）
